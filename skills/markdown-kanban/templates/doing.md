# Doing

> **What lives here**: only tickets actually being worked on right now. No finished tickets, no strikethrough, no "moved to done.md" pointer lines.
> **Approval before coding**: medium, large, storm
> (options: `all` | `medium, large, storm` | `storm only` — edit this line to change the policy)
>
> **Start ritual** (every ticket):
> 1. **Move** — cut the whole ticket from `backlog.md` into "In progress" below.
> 2. **Verify** — check the current code and data against the ticket. If they disagree, stop and report.
> 3. **Plan** — a few lines for a small ticket; a full plan for medium/large. 🌩️ storm tickets: re-review the design first.
> 4. **Approve** — if the policy above covers this ticket, wait for the owner's OK before writing code.
> 5. **Build.**
>
> **Finish**: cut the whole entry to the top of `done.md` (read only its header and newest entries; don't read the whole history). When nothing is in progress, write the placeholder. Last sub-ticket of a parent done → run the parent's **Integration** check before closing the parent.
> **Blocked**: keep the ticket here, append `— ⛔ blocked YYYY-MM-DD: waiting on <who/what>` to its title, and say what would unblock it.
